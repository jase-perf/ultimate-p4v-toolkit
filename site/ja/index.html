ULTIMATE P4V TOOLKIT

無料  ·  インストール不要  ·  P4VとP4Adminで動作

P4VとP4Adminに新しいタブと右クリックツールを追加します。誰が何をチェックアウトしているか、サーバ全体で何が変更されているか、容量がどこで使われているかがわかります。

ツールはP4Vの中で、今お使いのログインのまま動作します。アプリのインストールもサーバ側の設定も必要ありません。ツールファイルをP4Vにインポートすればすぐに使え、ツールキットが更新されると自動的に最新版になります。

1分でインストール

ステップ 1

ツールをダウンロード

P4V用
↓ p4v-tabs.xml 5つのタブ。まずはこちらから。 ↓ p4v-right-click-tools.xml Revert Exclusive Checkouts（管理者向け）とVirtual Stream Utility。 ↓ p4v-custom-tools-pc.xml Export .p4config（Windows PC用） ↓ p4v-custom-tools-mac.xml Export .p4config（Mac用）
P4Admin用（管理者向け）
↓ p4admin-tabs.xml Typemap EditorとAI Help（P4Adminのタブとして） ↓ p4admin-custom-tools-pc.xml Reset User Password（Windows PC用） ↓ p4admin-custom-tools-mac.xml Reset User Password（Mac用）
ステップ 2

インポートする

各ファイルは Tools > Manage Tools の中の、それぞれ決まった場所にインポートします。下記の項目を選んでImportをクリックし、ファイルを選択してください。

  • p4v-tabs.xml：P4Vの HTML Tabsに。タブは Viewメニューから開きます。
  • p4v-right-click-tools.xml：P4Vの HTML Windows（別ウィンドウで開くツールのP4Vでの呼び名）に。ファイルやフォルダを右クリックするとRevert Exclusive Checkouts、バーチャルストリームを右クリックするとVirtual Stream Utilityが使えます。
  • p4v-custom-tools-pc.xmlまたは p4v-custom-tools-mac.xml：P4Vの Custom Toolsに。 Toolsメニューから実行します。
  • p4admin-tabs.xml：P4Adminの HTML Tabsに。タブは Viewメニューから開きます。
  • p4admin-custom-tools-pc.xmlまたは p4admin-custom-tools-mac.xml：P4Adminの Custom Toolsに。ユーザを右クリックして使います。

インポートの前に、P4Vがファイル内のツールを一覧表示します。不要なものはチェックを外してください。(Admin)と付いたツールは管理者とスーパーユーザしか使えないので、それ以外の方は外して構いません。

ツールが読み込まれない場合は、 Preferences > HTML Tools の許可されたベースURLを確認してください。リストが制限されている場合は、https://jase.townを追加する必要があります。

チームで使う場合：サーバ管理者がP4Vの参照先をこれらのファイルに設定すれば、インポートなしで全員にタブと右クリックツールを一度に配布できます。コマンドは下の手動インストールをご覧ください。

データは外に出ません

ツールはあなたのログインを使い、P4Vを通じてP4 Serverからデータを取得します。並べ替えや集計、描画はすべてお使いのコンピュータ上で行われ、サーバのデータが外部に送られることは一切ありません。Server Activityの履歴も、お使いのコンピュータ内にだけ残ります。

唯一の例外はAI Helpです。入力した質問を、回答を得るためにPerforce公式のAIサポートアシスタントへ送信します。
