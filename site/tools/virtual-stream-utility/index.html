Virtual Stream Utility

A virtual stream shows part of its parent's files without copying them. Tick the folders and files it should show, check the Paths it will get, and save.

Parent's files

Click a folder's arrow to see what's inside. Ticking a folder takes everything in it, including files added to it later.
