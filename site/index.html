ULTIMATE P4V TOOLKIT

Free  ·  Nothing to install  ·  Works in P4V and P4Admin

New tabs and right-click tools for P4V and P4Admin. See who has what checked out, what's been changing across the server, and where all the space is going.

They run inside P4V using the login you already have, so there's no app to install and nothing to set up on the server. Import one file and they show up in P4V, and they update by themselves whenever the toolkit does.

install in a minute

Step 1

Turn on HTML Tools

In P4V, open Edit > Preferences (on macOS, P4V > Preferences), go to the HTML Tools page, and switch HTML Tools on.

P4Admin has the same setting.

Step 2

Download the tools

↓ tabs.xml The five tabs. Start here. ↓ windows.xml Right-click tools for P4V ↓ p4admin-windows.xml Right-click tools for P4Admin
Step 3

Import them

Go to Tools > Manage Tools, pick HTML Tabs… (or HTML Windows… for the window files), click Import, and choose the file.

Open the new tabs from the View menu. Right-click tools appear when you right-click files and folders.

Running a team? A server admin can give everyone the tabs and windows at once, with no importing, by pointing P4V at the same files. See Manual install below for the commands.

Set up tools one at a time, or for your whole team
