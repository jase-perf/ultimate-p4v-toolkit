Ultimate P4V Toolkit

Custom tools for P4V and P4Admin, served from this site. Add a tool by pointing a P4V or P4Admin tool definition at its URL. There's nothing to install.

Adding a tool

Turn on HTML Tools in Edit > Preferences > HTML Tools. Then go to Tools > Manage Tools and add an HTML Window or HTML Tab with the URL and settings below.
