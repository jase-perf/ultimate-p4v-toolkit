# Ultimate P4V Toolkit

A collection of custom tools for P4V and P4Admin. Most are HTML tools served from GitHub Pages. A few are command-line Custom Tools that run a short inline script, for things the P4V JavaScript API can't do. Import the definitions into P4V yourself, or publish them from your P4 Server so your whole team gets them with nothing to install.

Work in progress.

**Tool URLs and setup details:** <https://jase.town/ultimate-p4v-toolkit/>. The site is published from the `site/` folder by GitHub Actions on every push to `main`.

|---|---|---|---|

| [AI Help](site/tools/ai-help/) | P4V HTML Tab | none | Everyone |

## Where your data goes

The tools get their data from your P4 Server through P4V with your login, and do all their processing on your computer. Nothing from your server is ever sent anywhere else, and Server Activity's saved history stays local. The one exception is AI Help, which sends the question you type to Perforce's official AI support assistant.

Tools that need elevated access check the current user's access level when they open. Users without it get a clear explanation instead of a raw permission error.

## Install

Download the definition files and import them. Modern P4V has HTML Tools on by default. If *Preferences > HTML Tools* limits the permitted base URLs, add `https://jase.town`.

The file names never use "windows" for P4V's HTML Windows, so "Windows" below always means the operating system.

| File | What's in it | Import it in |
|---|---|---|
| [`p4v-tabs.xml`](https://jase.town/ultimate-p4v-toolkit/xml/p4v-tabs.xml) | Active Files, Server Activity, Depot Size Map, Typemap Editor and AI Help, with tab icons | P4V: *Tools > Manage Tools > HTML Tabs > Import* |
| [`p4v-right-click-tools.xml`](https://jase.town/ultimate-p4v-toolkit/xml/p4v-right-click-tools.xml) | Revert Exclusive Checkouts and Virtual Stream Utility | P4V: *Tools > Manage Tools > HTML Windows > Import* |
| [`p4v-custom-tools-pc.xml`](https://jase.town/ultimate-p4v-toolkit/xml/p4v-custom-tools-pc.xml) / [`p4v-custom-tools-mac.xml`](https://jase.town/ultimate-p4v-toolkit/xml/p4v-custom-tools-mac.xml) | Export .p4config, for a Windows PC or a Mac | P4V: *Tools > Manage Tools > Custom Tools > Import* |
| [`p4admin-custom-tools-pc.xml`](https://jase.town/ultimate-p4v-toolkit/xml/p4admin-custom-tools-pc.xml) / [`p4admin-custom-tools-mac.xml`](https://jase.town/ultimate-p4v-toolkit/xml/p4admin-custom-tools-mac.xml) | Reset User Password, for a Windows PC or a Mac | P4Admin: *Tools > Manage Tools > Custom Tools > Import* |
| [`p4admin-right-click-tools.xml`](https://jase.town/ultimate-p4v-toolkit/xml/p4admin-right-click-tools.xml) | Revert Exclusive Checkouts for P4Admin (optional) | P4Admin: *Tools > Manage Tools > HTML Windows > Import* |

Each tool is offered one way, as a tab or a right-click tool, so it isn't listed twice in P4V's menus.

When you import a file, P4V lists the tools in it so you can untick the ones you don't want. Tools that need elevated access say so in their name, like *Typemap Editor (Admin)*, so other users can leave them out.

The files point at the live site, so tools update by themselves when this repo changes. To give everyone in P4V the tabs and right-click tools, a server admin can point P4V at the same URLs instead:

```
p4 property -a -n P4VJS.HTMLTabs -v https://jase.town/ultimate-p4v-toolkit/xml/p4v-tabs.xml
p4 property -a -n P4VJS.HTMLWindows -v https://jase.town/ultimate-p4v-toolkit/xml/p4v-right-click-tools.xml
```

The files are generated by `scripts/build_install_xml.py`, and the icons by `scripts/make_icons.py`.
